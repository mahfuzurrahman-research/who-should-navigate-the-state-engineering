# Capability Matrix

| Capability | Public evidence |
|---|---|
| Python | validation, analytics, orchestration, reporting |
| R | independent raw-table feature construction and QR weighted regression; two score covariance conventions |
| SQL / DuckDB | staging, normalized core tables, marts, QA |
| Data modeling | encounter and PSU relations with explicit keys |
| Data quality | domain, uniqueness, exact weight joins, finite values, PSU nesting, rank/condition checks |
| Feature integrity | fixed reference, interaction, ordered features, frozen matrix and source hashes |
| Weight integrity | raw/normalized lineage, scale-invariance tests, keyed joins and independent SQL reconstruction |
| Cross-language validation | complete designs, coefficients, standard errors, covariance cells, predictions/residuals and diagnostics |
| Testing | unit, integration, negative/failure-mode tests |
| CI | required-R validation, test execution, Docker build/run, output upload; check Actions for execution status |
| Docker | configured Python + base-R container; local Docker execution was unavailable |
| Reporting | JSON, Markdown, HTML dashboard |
| Reproducibility | combined runner, staged statistical results, process lock, source/artifact receipts and verification CLI |

The matrix makes no claim about private empirical results or enterprise production deployment.
